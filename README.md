# QuestBook

A readable page for the quests you already accepted — for World of Warcraft:
Forever (and retail). No navigation help, no pins, no automation: you chose to
play the game; this just makes the text worth reading.

- `/qb` or a keybinding (Options → Keybindings → AddOns → QuestBook) opens the
  book: quest list left, big quiet readable page right.
- **Walk-and-listen:** start moving while reading and the book docks to the
  left and reads the quest aloud (game TTS) while you head out.
  `/qb voice` toggles; `/qb voices` + `/qb usevoice <id>` pick the voice.
- `/qb size <n>` body font size · `/qb dark` backdrop · X or Escape closes.

## Install
Clone (or unzip a Release) as `Interface/AddOns/QuestBook`. The repo root is
the addon root.

## Branches
`main` = known-good · `dev` = live iteration (beta lab runs on dev).
