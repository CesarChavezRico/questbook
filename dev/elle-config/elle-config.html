EllesmereUI offline configurator

Load EllesmereUI.lua from WTF/Account/<account>/SavedVariables/. Nothing leaves this page: the file is read and edited in the browser.

  1. Keep a copy of the original file.
  2. Edit here and press "Download edited file".
  3. With the game fully closed, replace the file in SavedVariables with the downloaded one.

The drawing is a layout mockup: position, size, spacing, shape and border. Fonts, textures, glows and spell icons are not drawn.

Elements

Layouts: keypad and mouse

Rebuilds action bars 1, 2 and 4 to 10 as the 4 × 3 keypad with its two thumb keys, and the mouse. Bar 3 is not touched. Building starts again from the loaded file.

Each column or row is its own bar. Only action bar 1 changes with your druid form by itself.
